# identikit-rs

Part of the [identikit](https://github.com/smorinlabs/identikit) family — tools for rewriting a live
template repo's identity into a new project.

**Status: reserved.** This repository holds the name; the project is not yet implemented.

- **Role:** command-line tool
- **Intended registries:** npm, PyPI, crates.io

See [smorinlabs/identikit](https://github.com/smorinlabs/identikit) for the working implementation.
